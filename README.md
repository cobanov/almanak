X hands over your posting history as a folder of JavaScript files nobody can
read. almanak turns it into a timeline you drag through, a gallery of every
photo, threads rebuilt into something readable, and analysis that states its
own denominators.

Drop your export in and it opens. There is no backend, so there is nowhere for
your archive to go.

## Privacy

- **No uploads.** Your export is opened by the browser, from your disk, and
  read there.
- **Direct messages are never read.** One allowlist decides every path the app
  opens, and a test suite keeps it that way.
- **No analytics, no tracking, no cookies.**
- **The build fails on a stray request.** `scripts/check-network.ts` rejects
  any `fetch` or hard-coded remote host outside two allowlisted modules, and
  the deployed headers carry a CSP that makes the browser enforce it.
- **Delete everything** clears every local store and reports what it cleared.

## Running it

```bash
npm install     # Node 22.6+
npm run dev     # http://localhost:5173/app/
npm test
npm run build   # static site into dist/
```

Serve it over **HTTPS**. The import flow uses the File System Access API, which
browsers gate on a secure context; over plain `http://` the page loads and then
cannot open a folder.

Chrome and Edge can open a folder. Firefox and Safari fall back to dropping the
ZIP, which works everywhere.

## The format

X's export is not what its documentation suggests, and it changes quietly.
[`docs/ARCHIVE-FORMAT.md`](docs/ARCHIVE-FORMAT.md) is generated by reading a
real archive:

```bash
npm run inspect -- /path/to/archive
```

Three traps it documents, each of which corrupts data silently: entity offsets
count codepoints rather than UTF-16 units; an edited tweet is stored once per
revision and only the newest carries real engagement; video filenames use a URL
hash where photos use a media id.

Search folds the dotted and dotless i together and peels stacked suffixes, so
`model` finds `modelleri` and `isik` finds `IŞIK`.

## Known limits

Note-tweet stitching and pre-2020 archives ship untested, because no archive
we have seen exercises them. Likes and retweets are as of the export date.
Retweet text is stored cut off by X. A reply's parent is not in the archive at
all, so the app draws the missing half as a labelled gap.
